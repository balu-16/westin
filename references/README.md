# Westin design references

## Current homepage direction — The Westin Skybook

The approved direction is now implemented locally in `Student_portal`. See the
[homepage asset archive and screenshots](homepage-rebuild/README.md),
[exact production artwork prompts](homepage-rebuild/prompts.md) and
[verification results](homepage-rebuild/verification.md).

- [Sky-blue hero concept](westin-skybook-hero.png) — 1717 × 916 PNG; generated desktop hero: an open book becomes a campus, with business/hospitality photo windows, a blue journey path and a college-age student turning the page.
- [Exact generation prompt](skybook-hero-prompt.md) — generated with the built-in image tool on 24 September 2026.

This is a visual proposal, not a screenshot of an implemented homepage. The architecture, people and photo windows are generated illustrations, not verified Westin campus/student imagery. The text wordmark is a placeholder; use the existing official logo in implementation. Small handwritten slogans inside the artwork are decorative generation output, not approved college copy. Final headings, navigation and buttons must be real accessible HTML, with the mobile composition specified separately in [plan.md](../plan.md).

The two original AI-generated concept images from the design discussion are copied here unchanged:

- [Bright & Youthful](bright-youthful.png) — selected direction: sky blue, rounded expressive headings, navy text, orange/mint accents and a playful login illustration.

These are visual references, not implemented pages. Their photography is illustrative, not verified imagery of Westin's students or campus. Use college-approved photography, official program names and the existing college logo for the eventual public site. The concept label “Portal Login” should become **Student Login** on that site; staff access remains separate.
